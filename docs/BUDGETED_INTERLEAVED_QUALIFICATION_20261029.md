## CPU reference

Retain the same six-block51.747M model, output projection, source scaling and
shared source/latent rotary convention. Zero latent tokens reproduce ordinary
prediction; one reproduces the existing interleaved model. Two append two
successive generated hidden states before predicting each authentic next token.

additional parameters, new normalization or learned router is introduced.

The explicit sequential reference has no future tokens in any prefix. Grouped
parallel storage uses chronological causal masks. A Jacobi refinement updates
each generated state from the output at its immediate predecessor. Full-gradient
tests compare converged finite substitution with the sequential computation,
check future invariance, and count actual forward/backward matmuls. These small
arrays are numerical fixtures, never a generated training or evaluation corpus.
