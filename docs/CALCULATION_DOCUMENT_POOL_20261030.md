# Prepare authentic calculation-containing TRAIN documents

The billion-target models have a useful equal-data text-prediction lead but
weak elementary and multi-operation arithmetic. A bounded source preparation
will establish whether more computationally relevant natural text is available
without a new architecture, supplied thoughts, generated problems or relabeled
answers. It admits no training or automatic replacement of the active study.

Use exactly the eight TRAIN shards already audited for the 3.783B ordinary
control. A document qualifies if the existing tested primitive or multi-
operation verifier finds at least one original explicit equality whose answer
matches its original premise and whose token boundaries round-trip exactly.
The primitive grammar is unchanged; the multi-operation grammar is unchanged.
Keep the entire original document prefix admitted by the parent index, not just
its answer or a rewritten task. No new text, reasoning trace or completion is
generated. Record calculation spans for later packing audits, never as extra
loss weights. Every prospective fit would still need its own frozen objective.

Retain all qualifying documents in a private candidate pool, with original
source identity, group, offset and length. Deduplicate repeated document IDs
and fail on conflicting ranges. Order by a fixed document hash. Report original
token capacity, source groups, operation counts, distinct expressions and
concentration. Do not sample a pool based on model losses, change the held-out
panels or open a protected reserve. The existing indexed TRAIN-group exclusions
remain binding. Shared elementary expressions across source groups are not a
claim of compositional transfer; the original harder panel's expression audit
stays unchanged.

The preparation only establishes feasibility for a later comparison in which
both ordinary and generated-state models receive the same authentic source
selection. A possible later design would preserve the 60/20/20 domain weights
while changing which mathematical documents are sampled, retain uniform NTP,
and report repetition and broad-loss retention. It must not quietly substitute
an enriched-corpus result for the original corpus result. No such fit, seed,
size, learning rate or duration is admitted by this document.

One attempt, four CPU workers, 20 minutes, 8 GiB per process and at most 256 MiB
of new private index artifacts. Keep the host-memory, disk and inode floors.
Record all costs, preserve stopped attempts and leave the active all16-chip
ordinary run and its 955 source bindings unchanged. No model scoring, chip
assignment, optimizer updates, confirmation data or alpha spending.
