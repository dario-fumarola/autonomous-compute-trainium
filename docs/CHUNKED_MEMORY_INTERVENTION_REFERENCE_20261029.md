This is a CPU reference and numerical software test, not a registered scientific
readout or an additional training arm. It has scored no authentic research
targets. It does not change the active qualification or sparse learning gates.

For exactly one supported latent slot per source chunk, recompute the full
chronological prefix. Authentic execution matches the existing independent
reference. The intervention preserves all source/latent positions, computation
rectangles and the current slot's self attention, but blocks every later query
from attending earlier latent keys. Recompute all downstream real and latent
states; do not reuse an authentic cache after changing the mask.

Tests verify the exact removed edges, preserved self attention, authentic-model
agreement, no effect before the first latent-memory read, causal prefix
consistency and identity when no slot fits in the context. All test token arrays
are numerical fixtures, not a synthetic research corpus.

If a future separately registered evaluation uses this helper, a degradation
would show dependence on the removed path. It would not alone demonstrate
reasoning or useful content: the mask is an intervention outside the trained
execution distribution. It must be interpreted alongside positive authentic
workspace utility, the independently trained constant-slot control, source
separation and transfer. There is no claim that the intervention is a supported
zero-compute deployment mode, and no new result may replace a failed broad-loss
efficiency comparison.
