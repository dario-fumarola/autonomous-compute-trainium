# Supplemental state and gradient validation

This is a prepared fallback only. It requires the preceding bounded recovery
to have closed with a timeout; a completed qualification needs no supplement.
The original failed qualification and its deadline are never rewritten.

Do not run a third full warm-up. Preserve all four completed cold numerical
checks and all 100 balanced warm measurements, requiring the original 2%
gradient-family, 0.003 loss, one-second update and 3x runtime-ratio limits.
Verify preserved checkpoint contents and full model/optimizer/RNG digests.

If complete update-103 and update-104 states and the mature gradient survived,
run only the independent fresh-process replay and global CPU gradient audit.
Otherwise register one missing update104 from the retained complete update103,
with exact restoration in every rank and full post-update replica verification;
then run its independent fresh-process replay and the global CPU audit. A
partial capture is never promoted into a completed original replica check.

This supplemental procedure has its own explicit 45-minute cap, 20-minute
Native phases and 15-minute CPU audit, four GiB additional artifacts and the
unchanged hardware/memory/disk/inode reserves. It does not pretend to have met
the original failed time budget. Retain and add all assigned costs from both
preceding attempts and the supplement, keeping opportunity time separate.

Every state remains disposable and excluded from scientific initialization.
No held-out targets, hyperparameter search, additional warm training or
scientific fit is part of this procedure. A failure does not automatically
start another retry. Only a complete combined numerical/state record can
support a separately registered learning comparison.
