This is an adaptive, retrospective DEV diagnostic, chosen after the first
matched-work seed favored one-pass training. It changes no primary, threshold,
inference exit or campaign deadline. Register before inspecting per-document
minima; execute only after both original work-control pairs complete all gates.

Reuse the already scored plain-NTP recurrent checkpoints from seeds5231/7283,
at supported depths1/2/3. Select the best weighted loss per whole document,
with free access to its true targets. Compare with each independently trained,
cooled, matched-work one-pass control separately. Do not select a different
baseline model per document. Preserve the60/20/20 domain weights and every
original document/group/target. Reproduce all aggregate scores and endpoint
identities before calculating minima.

The zero-penalty result is an optimistic quality bound over these recorded
paths, not a deployable policy. Also report a fixed grid of penalties against
nominal inference matrix work. Charge each document its number of1024-position
windows times the full-window forward ledger at its selected depth. Normalize
to the same family at one pass. This idealized accounting excludes selection,
KV-cache serving, communication and padding-kernel overhead; measured prefill
latency remains separate. Do not infer hardware efficiency from this bound.

If even the unconstrained, target-informed bound loses, a whole-document
selector restricted to these same predictions cannot close that loss gap.
This does not bound token routing, changed hidden trajectories, other training
or architectures. A favorable bound would provide headroom, not evidence that
a prefix-only selector can realize it. No new model forwards, updates, source
