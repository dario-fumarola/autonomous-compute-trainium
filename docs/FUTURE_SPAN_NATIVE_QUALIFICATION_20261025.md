# Future-span qualification,not scientific training

Only after all nine predecessor fits and all nine numerical gates complete,
with successful native closure receipts,may this queue claim the instance.
An idle gap between predecessor phases is insufficient. Read-only predecessor
CPU scoring may finish concurrently. The new qualification does not inspect
scores to select cases and never launches scientific training automatically.

Four fixed cases cross deterministic-one/sampled-recurrence with auxiliary
weight0/0.1. They share the prepared random qualification initializer,source
order,head and loss. Full gradients traverse every sampled step in both
recurrent cases. No qualification weights may initialize a scientific fit.
The natural source/context/target policy and horizon32/stride16 stay fixed.

Each case runs121 actual updates:20 startup/warmup,100 measured updates with
changing schedule scalars,and one post-checkpoint update. A fresh process
restores the exact120-update state and performs the same next update. This is
488 global qualification updates across four cases/replay paths,not488 new
research training updates. All replica work and repeated labels are charged.

Capture the complete512-window raw gradient at initialization and after120
updates. Check against the pinned upstream FP32 backbone,an independent dense
presence-loss construction and exact supplied initial states. Keep the2%
gradient gates for body families and the new head's weight/bias individually;
keep0.003 absolute loss gates for ordinary and future losses. Check clipping,
independent released optimizer arithmetic and moments using the observed raw
gradient. Historical moments are transferred by parameter name with a tested
adapter. Check the new head's optimizer state separately.

Recovery must preserve complete model/optimizer,RNG,source/auxiliary counters
and signature on load. Every replica must agree. The independent trained
gradient may be reused for replay only if model,source,depths and the exact
supplied latent states are identical. The replay's actual gradient and next
optimizer update still receive direct numerical comparisons. This does not
promise a bit-identical future trajectory across native processes.

Use the unchanged isolated SDK and primitive attention path,FP16 body,FP32
ordinary/auxiliary heads and master/moment tensors,manual scale8192 and unscale
before finite clipping. Use the qualified runtime-scalar Muon path and unscaled
fused AdamW,without optional AMP metadata. Reject unexpected CPU fallbacks.

Cap execution at90minutes after verified hardware admission,including CPU
audits;cap each native phase at15minutes and each CPU audit at20minutes.
Waiting for the predecessor is separately recorded and does not reset an
already admitted execution deadline. Resume validates the saved source list
and original deadline,reuses completed receipts and refuses partial phases
without an explicit recovery registration. A controller lock prevents duplicate
execution. Ordinary failures cancel only this queue's owned workers and CPU
process groups. Host/disk reserves remain512GiB/35GiB.

Report cold/startup time,100-update throughput,checkpoint/replay costs,native
and CPU attempts,all failures,assigned chip-hours and whole-instance opportunity
cost. Matrix estimates include both heads and every replica's Muon work;
zero-weight control pruning,tile padding,optimizer pointwise work and network
cost require separate measured reporting. No data-matched gain implies
efficiency. Passing this qualification only permits a separately registered
finite scientific budget after reviewing the current pilot.
