# Prospective persistent-state learning comparison — not admitted

Execution qualification is in progress. This document specifies the next
scientific question, not an automatic launch or a replacement for prior
negative results. A measured immutable plan must precede fitting.

The mechanism generates a continuous hidden state at each source position and
lets subsequent positions attend to it. Two fixed Jacobi rounds approximate
the coupled causal history during training. Only original authentic next-token
labels receive uniform NTP loss. There is no teacher, generated research corpus,
policy-gradient reward, router, target reweighting or detached latent gradient.
This bounded small-model discovery test does not launch the full learning-age
or large-model from-scratch confirmation program.

Compare three independently tuned predictors at the same natural-source
exposure: ordinary; generated persistent states; trained constant pause states.
Use the already qualified51.75M shape, same initialization within seed, tokenizer,
source packing, masks, source order and optimizer family. The six-billion-position
index is available, but maximum fitted exposure must leave the numerical-audit
windows untouched. Both unscored source reserves remain closed.

Choose each arm's learning rate with the same registered small grid and tuning
budget, followed by a fresh initialization and complete warmup/stable/cooldown
schedule. Do not promote a highest-grid setting as a bracketed optimum. Freeze
all endpoints before scoring; no extension from a cooled checkpoint. Every
endpoint needs the mature full-global gradient and complete-state audit.

First ask whether the generated-state predictor improves held-out natural NLL
beyond both ordinary and constant-pause models at equal data. Report the full
60/20/20 aggregate, every domain, and the existing dependency panel. A gain on
one selected slice does not replace the broad comparison. Qualification losses
and throughput are not learning evidence.

Also include an ordinary endpoint with the same total nominal training matrix
work. Report actual full execution time separately, including unsuccessful
attempts, tuning, compilation, audits and readout. Any later practical efficiency
claim must additionally survive a tuned conventional shape alternative; the
same-family ordinary ablation alone is insufficient.

Mechanism diagnostics need to separate generated-state content from extra
processing. A trained pause model is the primary cheap control. Evaluation
interventions must preserve prefix causality and recompute every affected
latent and K/V state. Damaging the model by permuting its internals does not,
by itself, demonstrate useful computation. Exact sequential execution and
finite-round convergence must be measured at learned weights before claiming
cheap cached inference. Jacobi round count is not a thought-budget scaling curve.

Promote a positive development lead only to a separately frozen fresh-source,
paired-seed test. Treat broad failure, lack of absolute utility and disagreement
with sequential inference as distinct limitations. No result in this screen
establishes autonomous allocation or transferable reasoning without those tests.
