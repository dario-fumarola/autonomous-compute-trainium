# Saved-weight attribution after the positive equal-data exposure result

This is a separately bounded CPU diagnostic of the already audited seed-730271
billion-target latent endpoint. Its equal-data broad and arithmetic gates have
passed. The ordinary matched-work fit continues unchanged; this diagnostic
cannot change its budget, scoring, advancement rule or reported conclusion.
No new fit, seed, parameter search, unsupported thought budget or confirmation
reserve is admitted here.

Freeze all 384 reused broad development windows and the complete 259-case
arithmetic subset, without choosing examples by model score. Use the same
source/target alignment, 60/20/20 broad weights and equal arithmetic-bin weights.
Read every authentic target using exact sequential FP64 execution. Freeze four
conditions before reading any intervention scores:

1. Authentic generated states, reproducing the published endpoint.
2. Current-only generated state: both source and latent queries cannot attend
   to any earlier latent slot. The current latent still reads the authentic
   source prefix and itself. All source states are recomputed under this mask,
   so past latent information cannot survive through source K/V.
3. Lagged input: after the first position, insert the previous position's newly
   generated state instead of the current generated state. Previous states are
   generated under this intervened history; the first position is unchanged.
4. Constant input: replace each latent input with the scaled mean input
   embedding, as in the trained pause control, using the latent model's weights.

Every condition retains source and latent slots, their rotary positions, both
body computations, dense attention dimensions and the vocabulary readout.
Unused generated outputs in the constant condition are still computed.
Current-only masks dense attention rather than claiming sparse execution.
Every changed input recomputes its K/V and all dependent later states. No donor
source, future target, answer-aware choice or cached original latent information
is supplied. These are interventions on trained weights, not trained alternatives
or validated deployment modes. In particular, current-only does not replace the
separately trained ephemeral-control experiment.

Before complete scoring, require cached/full-prefix agreement on the first
three frozen arithmetic prefixes (up to 16 positions), and batch/individual
agreement, in every condition, maximum log-probability error 1e-8. CPU fixture
tests also verify full gradients, future invariance, authentic-path equivalence,
constant-input equivalence and current-only equivalence to the independent
existing ephemeral implementation. No random fixture enters research data.
Authentic scores must match the saved full-panel endpoint within 1e-8.

Report each condition's absolute broad/domain, answer, first-answer and exact
answer-prefix metrics; paired removal penalties are intervention minus authentic
loss, with 2,000 conditional source-bootstrap draws, seed 40537. Keep all bins
and all conditions, including a beneficial intervention. Intervals are
exploratory, conditional on one trained seed and adaptively reused development
sources; no terminal alpha is spent and no significance-based promotion follows.

Interpretation is limited. Removing a path without changing prediction gives
no evidence that the path is useful at this endpoint. Harm after removal shows
dependence, but may reflect distribution shift. Combined with the trained pause
comparison it motivates a separately trained memory control; it does not by
itself show a reusable algorithm, reliable arithmetic, additional-budget
scaling, allocation or training-compute efficiency. No result from this
readout can overturn a failed conventional matched-work comparison.

Use four low-priority CPU workers with two intra-op threads each, at most 6 GiB
RSS per worker, 512 GiB host MemAvailable, 35 GiB output-filesystem and 10,100
inode floors. Cap the entire readout to one hour from registration. Zero
accelerator chips and zero optimizer updates. Record CPU usage, wall time and
whether the existing all-chip run overlaps; do not double-add reservation
opportunity cost. The diagnostic runs from an isolated checkout and does not
edit the active trainer's frozen source. Preserve all failures without retry.
Publish only code, hashes and aggregates; no source text, token arrays, private
case identifiers, model tensors or per-example scores.
