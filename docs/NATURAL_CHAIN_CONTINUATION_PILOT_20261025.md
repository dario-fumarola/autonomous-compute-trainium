200-update base endpoints,0.001 peak rate,0.3 answer/0.03 EOS loss weights,
128 NTP windows plus applicable128 tasks per update,curriculum quarters or
one-pass versus4/1/2 full-gradient depth schedule. It is a one-pair development
continuation,not the original from-scratch/general-text success criterion.

All conditions start from the original completed One/NTP seed5231 body at
1.004887590B natural targets. Reset optimizers identically. No fitted driver-

stream at window1920*512 without wrapping. The paired order of new NTP windows

problem stream;all views of a problem are one example,not independent data.

answer. No teacher-model,numerical answer generation,RL or new architecture.

One/bridge only because that update's data,depth,objective,rate and optimizer
are exactly identical. No cooled checkpoint is extended.
