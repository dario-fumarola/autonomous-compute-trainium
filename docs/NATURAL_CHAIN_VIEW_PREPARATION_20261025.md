# Original arithmetic conclusion views

Construct a TRAIN-only data view from the1,727 frozen source-chain candidates.
This instantiates the owner's bridge-hiding proposal in a narrower,exactly
checkable domain. No new numeric premise,worked step or answer is generated.
Every mathematical string is an unchanged original source substring;fixed
English task delimiters only specify what the model must predict.

Retain one document per literal-valued canonical arithmetic AST,chosen by
ascending content ID. Require a scalar conclusion,exact original equalities,
at least two premise operations and an original simplifying intermediate.
Reject answer literals already present in any original retained fragment.
Prepare every visible original-work prefix from all steps down to none. All
views of one problem belong to the same task;none are independent samples.

Use the existing pinned32k tokenizer. The normal decoder predicts the ordered
original conclusion;mask every premise,visible worked step and task delimiter.
Require stable tokenization at the answer boundary and sufficient context128
for all views,including explicit EOS. Never truncate a premise or target to
fit. Score original answer tokens separately from a single task-EOS target;
EOS is formatting supervision,not an authentic source token. A prospective
training objective may weight EOS separately and must declare that weight.
No hidden work is encoded,cached or supplied to the model.

The exact-rational evaluator only verifies scalar outputs and source equality.
It never supplies the decoder's answer labels. Reject unsupported scalar
formatting;do not repair documents or rewrite targets. Hash all private views
and retain source character/UTF8 spans,identity and parent manifest links.

This preparation opens no DEV,TEST,reserve or model scores and admits no fit.
TRAIN-only reconstruction can support a bounded training learnability check,
not held-out scientific efficacy. Any continuation pilot must disclose its
pretrained history/reset optimizer and cannot establish from-scratch learning.
A later curriculum study needs paired one-pass/recurrence training,stronger
work-matched baselines,fresh eligible evaluation groups and free generation.

CPU-only preparation is bounded to600 seconds,four readers at most,512GiB
MemAvailable and35GiB free output filesystems. Keep source contents,token arrays,
views and states private. Publish aggregate counts,hashes and failures only.
