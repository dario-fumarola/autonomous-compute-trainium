# Longer natural-data reserve

This is data preparation, not a new model experiment or an extension of the
running frozen campaign. The ongoing research objective needs the ability to
test mature training, rather than repeatedly stopping at roughly1B targets.
Preparing source capacity does not establish that longer training will help.

Append10.5B targets to the independently audited6.5B stream, giving roughly
17B without changing any existing packed position. The additional mix remains
60% web,20% mathematical web and20% repository code. Retain the pinned32k
tokenizer, natural-source filters, permissive-code license filter, source-group
split and approximate lexical near-duplicate rules. No generated corpus,
teacher, RL, evaluation scoring or checkpoint migration is involved.

The web reserve adds the2013-48 and2014-10 FineWeb-Edu crawls at the existing
immutable revision; math and code use further files from their existing pinned
repositories. Official source listings were checked before registration.
These later web crawls change the future sequential source distribution;
any later comparison must expose its arms to the same declared stream and
report that change. They are not silently substituted into the current fits.

All three earlier corpus generations are explicit inputs. Their manifest and
source lineage, accepted-document databases and raw-source checksums must
match. Rebuild duplicate sketches for every prior accepted document plus the
fresh protected panels before admitting TRAIN. Protected TEST is read only
for content identity/group exclusion, never scored or used for model choices.
It cannot confirm a new intervention after its current confirmatory use.

Use12 CPU workers at low scheduling priority, three download threads and the
existing512GiB memory/35GiB disk reserves. Bound preparation to03:50 UTC and
the independent audit to04:10 UTC on October24. Keep all raw sources, tokens,
SQLite databases and raw-source path maps private on the new instance NVMe.
Count failures and partial work in an execution receipt. An incomplete job
is not a usable frozen corpus.

An independent audit must check the full parent numeric prefix, all prior and
new packed checksums, vocabulary/mask validity, every stored window-prefix
target count, all-generation exact-document isolation and protected groups.
Approximate raw-text duplicate screening is not independently repeated by
that audit; report this limit. Model-source migration and any longer run still
need their own qualification and measured scientific budget.

The new CPU fixtures exercise missing/reordered corpus generations, identical
filenames from different crawls, private raw-source maps, interior target-count
corruption, invalid masks and out-of-vocabulary IDs. Fixtures are software
checks and never enter research data.
