# Probability replay: finite early-learning mechanism screen

The owner authorizes continuing toward learned intermediate computation. This
is one bounded small-model discovery test of the independently implemented
[probability-embedding reference](PROBABILITY_WORKSPACE_20261028.md). It is not
the full from-scratch campaign, a replication of PonderLM, or a reopening of the
closed sparse-feedback and frozen-feature negatives.

Qualification precedes admission: the complete small-array Native/CPU fixture,
actual62.8M shape,100 warm updates at local batch4, independent full-global
mature gradients and exact separate-process model/AdamW/RNG replay. The initial
batch4 controller stopped at host-memory admission before replay; recovery only
completes the unstarted replay/audit and retains all original costs. No
qualification weights enter science.

Model:16 layers,width512,8 query/4 KV heads,SwiGLU1376,tied32000 vocabulary,
512context,62,800,384 parameters. Random seed9511; original pinned Mistral32k
tokenizer,not OLMo token IDs. Uniform real-source NTP; no teacher,synthetic source
examples,auxiliary objective or policy gradient. Full softmax expected embeddings
are added to the input stream before complete causal recomputation. All proposal
and reader operations are differentiated. Zero replay is exactly ordinary NTP.

Four arms start at identical weights and source order. Workspace trains balanced
blocks containing zero/one/two extra passes in a pre-frozen randomized order to
the first whole block beyond200M real targets. Ordinary-data trains the same
number of updates. Ordinary-work trains enough whole updates to match all of
workspace's dense matrix work. Uniform trains the same real targets with two
constant mean-embedding additions; it does not execute proposal body/head passes
and is explicitly cheaper. No new parameters distinguish these arms.

One shared learning-rate opportunity is fixed before scores:AdamW peak1e-3,
betas(.9,.95),epsilon1e-8,matrixWD0.1,embedding/normWD0,clip1. Warm up32updates,
hold peak,then independently cosine-cool each final endpoint over its last10%
to0.1peak. Localbatch4×64ranks. This is an initial-learning screen with a fixed
recipe,not independently tuned conventional-frontier superiority. The earlier
approximately64M workspace/ordinary-data checkpoints are uncooled descriptive
learning-curve points,never compared as final converged results.

The data acceptance receipt freezes640M source positions,60/20/20 scheduling,
151341 training source groups and384 disjoint broad development groups. The
broad evaluation window is chosen by a frozen hash within each source's admitted
prefix,without model scores. All320 protected confirmation groups remain sealed.
Retokenized original natural-dependency cases retain their complete prefix and
source-authored target:134 arithmetic conclusions,110 exploratory intermediate
expressions and9 code names fit512positions.87 cases are excluded by the context
or target cap. Code-name prediction alone is not multi-step reasoning. These
are development cases,not a fresh terminal benchmark.

At every retained checkpoint,full replicas must agree; complete model/optimizer/
RNG restoration and independent CPU SDPA/CE full-global gradients must pass the
original2% family and0.003 loss gates before any model is scored. All scientific
arms must pass before joint evaluation. The disposable qualification establishes
separate Native next-update replay; scientific audits do not claim a second
independent Native replay for every saved endpoint. Each evaluation uses fresh
Native processes and independent CPU per-target parity at2e-4.

Report every supported zero/one/two exit at initialization,early and final
workspace checkpoints. Report ordinary equal-data/equal-work and uniform
endpoints. A fixed vocabulary-to-embedding permutation at the final two-pass
readout tests content dependence,with the full branch recomputed. It preserves
distribution entropy and nominal work but creates distribution shift; degradation
alone cannot establish reasoning. Never select a proposal with the true target.

Broad primary development measure is60/20/20 weighted real-target NLL,with all
domain signs retained. Also report source-group conditional95% intervals,first
target and full-answer NLL on every dependency category. Useful supported
iteration is a>=0.01-nat gain of final two-extra-pass over its supported one-extra
exit with conditional lower bound>0. Independently report the same practical
criterion versus ordinary equal-data and equal-work. These are single-seed
screening gates,not confidence about training-run variation. No automatic router,
larger fit or confirmation follows any outcome. A null cannot close the broad
mechanism or claim that smaller models cannot think.

Register exact updates,source counts,executed matrix work and source hashes in
the machine plan before fitting. Count every tied vocabulary projection,expected
embedding multiplication,body pass and backward. Report actual wall/chip time
separately,including compilation,audits,source preparation and failed attempts.

phase,192GiB worker,512GiB host reserve,35GiB output floor,10000 inodes and10GiB
artifact allowance. This finite limit bounds the experiment;it does not end the
