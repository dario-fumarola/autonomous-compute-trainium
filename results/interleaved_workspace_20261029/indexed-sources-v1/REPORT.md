# Indexed natural-source preparation

The source-only audit passes. A virtual packing index exposes 6,000,000,000
positions from the accepted natural-corpus extension, including unscored
document boundaries. The 5,359,930 documents belong to 571,602 TRAIN source
groups. Actual natural targets are 3,593,568,083 web, 1,197,856,263 math and
1,197,855,794 code. Every natural target is counted once.

The reader reproduces 515 independently reconstructed edge/random windows from
the original immutable source arrays. Source-group and protected-group overlap
are zero under the frozen split and exclusion inventory. Original source bytes
are not copied; the index and private membership records use 1,405,198,179 bytes.
Preparation took 247.00 seconds, with 21,868,023,808 bytes peak process RSS,
zero accelerator allocation, no optimizer updates and no model scoring.

This is an additional validated source pool, not a scientific training admission.
The existing scientific histories and datasets are unchanged. No fresh reserved
evaluation source has been scored. Private text, token arrays and membership
records are excluded from the public repository.
